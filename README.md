# color-concept

A logical UI color palette generator that automatically calculates harmonious colors and exports them as SCSS variables.
Color Concept is a logical UI color palette generator designed for developers and designers.
Simply pick a primary color, and the tool automatically applies color theory to generate harmonious base tones, a high-contrast complementary accent color, and accessible font colors. You can preview the palette on UI components in real-time and download the generated colors as ready-to-use SCSS variables.


## Features
- 🎨 **Logical Color Theory:** Automatically calculates monochromatic base tones and complementary accents.
- 👁️ **Accessibility First:** Dynamically adjusts text color (black/white) based on background luminance for optimal readability.
- ⚡ **Live UI Preview:** Test your generated palette instantly on buttons and input fields.
- 📦 **SCSS Export:** Download your palette as `_color-variable.scss` with a single click.
- 🚀 **Zero Dependencies:** Built with pure HTML, CSS, and Vanilla JavaScript.
